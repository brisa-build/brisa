This release brings several important maintenance updates and new features as we continue to strengthen Brisa’s foundation across platforms — especially improving reliability for Windows users and extending configurability for advanced builds.

We’ve also welcomed **three new contributors** to the project — thank you for helping Brisa grow! 💨

## 🚀 What's Changed
  
- **feat(github):** add Discord link to ISSUE_TEMPLATE by [@heygsc](https://github.com/brisa-build/brisa/pull/880)
- **feat(build):** expose new `minify` configuration field in the build process by [@aralroca](https://github.com/brisa-build/brisa/pull/888)
- **fix(windows):** resolve critical build failure caused by incorrect temp directory path for layout compilation by [@Atharva1723](https://github.com/brisa-build/brisa/pull/896)
- **chore:** upgrade Bun multiple times for stability and performance by [@aralroca](https://github.com/brisa-build/brisa/pull/882), [#889](https://github.com/brisa-build/brisa/pull/889), [#891](https://github.com/brisa-build/brisa/pull/891)
- **chore:** improve Husky setup and Biome upgrades by [@aralroca](https://github.com/brisa-build/brisa/pull/883), [#884](https://github.com/brisa-build/brisa/pull/884)
- **chore:** upgrade Tailwind, PandaCSS, and other build dependencies by [@aralroca](https://github.com/brisa-build/brisa/pull/887)
- **docs:** update Brisa contact email (removed “.com”) by [@ericaig](https://github.com/brisa-build/brisa/pull/892)
    

## 🌱 New Contributors

- [@heygsc](https://github.com/heygsc) – added Discord to issue templates 
- [@ericaig](https://github.com/ericaig) – improved project documentation   
- [@Atharva1723](https://github.com/Atharva1723) – fixed a major Windows build issue
