It’s been a few weeks since our last release — I’ve been on vacation recharging batteries ☀️ But Brisa hasn’t stopped moving forward! Today we’re publishing **v0.2.14**, a release focused on improving the development experience on **Windows**, cleaning up old warnings, and updating docs.

## 🛠 Fixes and improvements in this release

- **Windows compatibility**: We've fixed key build issues when using Brisa on Windows, including problems with temporary folders, path resolution, and file system race conditions.
- **Build warnings cleanup**: Old warnings related to CSS Modules used inside Web Components have been removed.
- **Better TypeScript experience**: The TypeScript docs have been updated and polished for clarity.
- **Bun upgrades**: We continue upgrading Bun in preparation for the next major release, ensuring better performance and compatibility.

And… 

we’ve got some thrilling news to share: **Brisa has been nominated for the Open Source Awards at GitNation**! 🎉 The winners will be announced **this Thursday**, and we’re incredibly honored to be among the finalists. Thanks for all your support!
